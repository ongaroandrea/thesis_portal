## LIGHTING CHECK

Evaluate only lighting. Ignore materials, textures, geometry, composition, render style, shaders, and post-processing.

Use only visible lighting evidence:
- shadow direction, density, edge softness, penumbra, contact shadows
- illumination gradients, hotspots, falloff, ambient or bounce fill
- color temperature
- reflections or highlights only when they indicate lighting
- visible emissive contribution

Never infer lighting from material/albedo, texture, geometry, blur, hidden lights, renderer settings, or artistic intent.

Silently identify each detectable light source, then compare type, direction, intensity, shadow behavior, falloff, ambient/environment contribution, and visible parameter effects.

Tie every reported parameter change to visible evidence. Output only in the required schema and enums.
