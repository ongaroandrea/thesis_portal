This document covers ONLY how HDRI environment lighting interacts
with PBR material parameters: roughness, metallic/dielectric
behavior, specular, Fresnel/IOR, alpha/opacity, and transmission.

Use this alongside parameter_explanation.txt. Do NOT use this
document to reason about texture patterns, UV mapping, geometry,
or camera changes.

================================================================
SECTION 1 — WHAT AN HDRI DOES IN THE SCENE
================================================================

Physical meaning:
    An HDRI (High Dynamic Range Image) is a 360-degree environment
    map used as the scene's light source and reflection source.
    Every reflective or refractive surface in the render shows
    some portion of the HDRI content, not a generic studio light.

Key consequence for material analysis:
    Reflections, highlights, and see-through content in Image A
    and Image B are largely IMAGES OF THE SAME HDRI, not
    independently generated light sources. When comparing Image A
    to Image B, the HDRI itself does not change between the two
    renders unless explicitly stated — only the material response
    to it changes. Any visual difference must therefore come from
    a material parameter, not from the environment map switching.

----------------------------------------------------------------
1.1 HOW HDRI STRENGTH AFFECTS THE WHOLE IMAGE
----------------------------------------------------------------
    - HDRI acts as both the light source and the background
      reflection source at once.
    - If HDRI strength changed, ALL surfaces get brighter or
      dimmer together, including diffuse (non-reflective) areas.
    - A material parameter change affects only the target surface,
      not the whole scene uniformly.
    - If brightness shifted uniformly across every object and the
      background alike -> environment/lighting change, not material.
    - If brightness shifted on one surface only, with everything
      else in the frame unchanged -> material change.

================================================================
SECTION 2 — PER-PARAMETER BEHAVIOR UNDER HDRI
================================================================

----------------------------------------------------------------
2.1 ROUGHNESS UNDER HDRI
----------------------------------------------------------------
Observable behavior:
    - Low roughness: the HDRI is visible as a sharp, recognizable
      mirror-like reflection (you can identify shapes/colors from
      the environment map in the surface).
    - High roughness: the HDRI content blurs into a soft gradient;
      individual environment features become unrecognizable.

HOW TO DISTINGUISH ROUGHNESS FROM HDRI CONTENT ITSELF:
    - A busy, high-contrast HDRI can make a smooth surface look
      like it has "detail" — this is reflected environment content,
      not a texture or roughness change.
    - Do NOT interpret visible HDRI detail in a reflection as a
      texture or roughness increase. Sharp environment detail in
      a reflection indicates LOW roughness, not added surface detail.
    - If the same HDRI features are visible but blurrier in B than
      in A -> roughness increased. If sharper -> roughness decreased.

----------------------------------------------------------------
2.2 METALLIC UNDER HDRI
----------------------------------------------------------------
Observable behavior:
    - Metallic = 1.0: the surface reflects the HDRI tinted by the
      base color; no diffuse contribution, so in directions of the
      HDRI with little light the surface reads as dark tinted.
    - Metallic = 0.0: the surface reflects the HDRI in white/
      achromatic form only at grazing/specular angles; the rest of
      the surface still shows diffuse base color lit by the HDRI.

HOW TO DISTINGUISH METALLIC FROM HDRI COLOR CAST:
    - A strongly colored HDRI (e.g. an orange sunset map) can tint
      dielectric diffuse areas too, through colored light, not
      reflection. This is a lighting cast, not metallic behavior.
    - Metallic tint follows the BASE COLOR of the object; an HDRI
      color cast follows the COLOR OF THE ENVIRONMENT MAP and
      appears on every object in the scene similarly.
    - If only one surface takes on a tinted, mirror-like copy of
      the HDRI while its own base color is absent from diffuse
      areas -> metallic increased.
    - If all surfaces share a similar color cast from ambient light
      -> HDRI color, not a metallic change.

----------------------------------------------------------------
2.3 SPECULAR / FRESNEL UNDER HDRI
----------------------------------------------------------------
Observable behavior:
    - HDRI environments typically contain bright regions (sun,
      sky, windows) and dark regions (ground, shadow side). The
      specular highlight seen on a surface is literally a small,
      distorted reflection of the brightest part of the HDRI.
    - Because the HDRI supplies ambient light at grazing angles,
      the Fresnel rim on dielectrics is often much more visible
      under HDRI lighting than under a single point light, since
      grazing angles are always catching SOME part of the
      environment.

HOW TO DISTINGUISH SPECULAR/FRESNEL FROM HDRI HOTSPOTS:
    - A bright spot that has a similar shape/size in the same
      screen position across Image A and Image B is likely the
      HDRI's brightest region reflecting normally -- expected,
      not evidence of a specular/Fresnel change.
    - A bright spot that appears, disappears, or changes size and
      intensity, with the HDRI otherwise unchanged and camera/
      object position unchanged, indicates the specular or
      Fresnel(IOR) value changed.
    - If the bright rim strength scales with viewing angle
      differently between A and B (rim present at fewer/more
      grazing angles) -> IOR or specular changed, not the HDRI.

----------------------------------------------------------------
2.4 IOR / TRANSMISSION UNDER HDRI (SEE-THROUGH SURFACES)
----------------------------------------------------------------
Observable behavior:
    - Transparent or transmissive materials show the HDRI (or
      objects/background in front of it) THROUGH the surface,
      bent by the IOR value.
    - Higher transmission: more of the HDRI/background is visible
      through the object, less surface-color tint.
    - Lower transmission: the object looks more opaque, the HDRI
      is only visible via reflection, not transmission.
    - Higher IOR: HDRI content seen through the object is bent/
      displaced more strongly and the Fresnel rim is more visible.

HOW TO DISTINGUISH TRANSMISSION/IOR FROM AN HDRI CHANGE:
    - If the HDRI content visible through the object shifts
      position or warps MORE than the same content visible via
      direct reflection elsewhere in frame -> IOR changed.
    - If the amount of background visible through the object
      changes (more/less see-through), with reflection strength
      elsewhere in the frame staying the same -> transmission
      changed, not the HDRI.
    - If the underlying HDRI pattern itself looks like a totally
      different environment (different sky, different horizon)
      between A and B -> the environment map changed, which is
      outside the scope of a material difference.

----------------------------------------------------------------
2.5 ALPHA / OPACITY UNDER HDRI
----------------------------------------------------------------
Observable behavior:
    - Lower alpha: the HDRI or scene content behind the surface
      becomes visible through it, similar to transmission but
      without refractive bending -- content behind is not distorted.
    - Higher alpha (toward 1.0): the surface becomes fully opaque
      and blocks the HDRI/background entirely.

HOW TO DISTINGUISH ALPHA FROM TRANSMISSION UNDER HDRI:
    - Alpha reveals background content WITHOUT bending it.
    - Transmission reveals background content WITH IOR-driven
      bending/displacement.
    - If what's visible through the surface lines up exactly with
      where it would be without the object -> alpha/opacity.
    - If what's visible through the surface is shifted or warped
      from its true position -> transmission/IOR.

================================================================
SECTION 3 — QUICK-REFERENCE: HDRI VS. MATERIAL CAUSE
================================================================

Signal observed                                  Most likely cause
------------------------------------------------------------------
Whole scene brighter/dimmer, all objects equally  HDRI strength, not material
One surface brighter/dimmer, rest unchanged       Material parameter on that surface
Reflection sharper/blurrier, same HDRI features   Roughness changed
Reflection tinted by object's own base color      Metallic increased
Reflection stays white/neutral                    Dielectric (metallic low)
Bright rim only at grazing/edge angles, new       Specular or Fresnel(IOR) changed
Same HDRI hotspot, same screen position, expected Normal HDRI reflection (no change)
Background seen through object, undistorted       Alpha/opacity change
Background seen through object, distorted/shifted Transmission or IOR change
Entire environment content looks different        HDRI/environment map itself changed
                                                   (outside material scope)

================================================================
SECTION 4 — GENERAL CAUTION
================================================================

Before attributing a visual difference to a material parameter,
confirm the HDRI itself is the same in both images (same visible
sky/ground/light pattern in unreflective background areas, if the
background is visible). If the environment map, camera, or object
pose also changed between Image A and Image B, isolate those
factors first -- only differences that persist after accounting for
lighting/environment and camera position should be attributed to
a PBR material parameter change.
